# Apple Product Prices

A single-page site, developed by [Anand Bongir](https://x.com/anand_bongir), that shows the price range of every current Apple product, from the entry configuration to the fully loaded one, in **eight countries**: the United States, India, the United Kingdom, the United Arab Emirates, Canada, Australia, Japan and Singapore.

Each row is one product. Dots mark every configuration on a shared price scale. Click a row to see the price ladder: storage tiers for iPhone and iPad, memory and storage upgrades for Mac, and size and connectivity for Apple Watch.

## Files

| Path | What it is |
|---|---|
| `index.html` | The page: layout, styles and rendering code. No build step. |
| `prices.js` | All prices, generated by `scripts/build_prices.py`. Sets `window.PRICES`. |
| `scripts/configs.json` | The Apple Store buy pages to read, and the option clicks that select each configuration. |
| `scripts/scrape.js` | Opens each buy page in headless Chromium and records the configured total and every option label (Apple prints the price difference on each label). |
| `scripts/build_prices.py` | Turns `raw/*.json` into `prices.js`, and prints what changed since the last run. |
| `raw/` | Latest scrape output, kept so each monthly update shows a diff. |
| `assets/` | Favicons and the share image (`og.png`). Regenerate with `node scripts/make-images.js` after editing `assets/favicon.svg` or `scripts/og.html`. |

## Where the prices come from

All prices are read from Apple's own online stores:

| Country | Store | Prices |
|---|---|---|
| United States | `apple.com/shop` | list prices, before sales tax |
| India | `apple.com/in/shop` | MRP, including GST |
| United Kingdom | `apple.com/uk/shop` | including VAT |
| United Arab Emirates | `apple.com/ae/shop` | including VAT |
| Canada | `apple.com/ca/shop` | before sales tax |
| Australia | `apple.com/au/shop` | including GST |
| Japan | `apple.com/jp/shop` | including consumption tax |
| Singapore | `apple.com/sg/shop` | including GST |

The only hand-entered prices are the Hermès Apple Watch rows (US starting prices from press coverage), because Hermès models are sold on a separate store.

To add a country, add its store URL to `BASE` and its currency marker to `CUR` in `scripts/scrape.js`, add it to `COUNTRIES` and `CUR` in `scripts/build_prices.py`, then scrape it with `COUNTRIES=xx node scripts/scrape.js all`.

## Updating prices

```bash
npm install playwright@1.48.2 && npx playwright install chromium   # once, if Playwright is not already available
```

```bash
node scripts/scrape.js all
```

```bash
python3 scripts/build_prices.py
```

The build script rewrites `prices.js` and lists every price that changed, every configuration that disappeared and any configuration it could not read. Check that list, then commit.

To scrape only some countries or pages:

```bash
COUNTRIES=uk,ae PAGES=imac,mac-mini node scripts/scrape.js all
```

To scrape one page while debugging:

```bash
node scripts/scrape.js uk macbook-pro
```

When Apple launches or retires a product, add or remove its page in `scripts/configs.json` and its row in `scripts/build_prices.py`.

## Hosting

The site is static and is served by GitHub Pages from the `main` branch root at [apple-product-prices.com](https://apple-product-prices.com) (DNS on Cloudflare, `CNAME` file in the repo).
